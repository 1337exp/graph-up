# graph-up

Визуальный редактор графов в духе Blueprint из Unreal Engine 5: ноды с типизированными пинами, потоком исполнения (exec) и передачей данных, которые можно собрать, запустить и посмотреть, как граф выполняется.

**Стек:** Vue 3 + TypeScript + Vite + Pinia. Тесты: Vitest + happy-dom.

## Быстрый старт

Нужен Node.js 22+.

```bash
npm install
npm run dev
```

Открой адрес из консоли (по умолчанию `http://localhost:5173`). В редакторе сразу лежит демо-граф из двух программ:

- **верхняя** (`Start` → `Branch` → `Print`) сравнивает числа и выводит результат;
- **нижняя** считает сумму `1 + 2 + 3 + 4 + 5` циклом `For Loop` через переменную `sum`.

Чтобы запустить нижнюю, выдели её `Start` и нажми **Run** (без выделения запускается первый `Start`). Включённая галочка «Slow» замедляет исполнение, и видно, как подсвечиваются ноды.

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с горячей перезагрузкой |
| `npm run build` | проверка типов (`vue-tsc`) и сборка в `dist/` |
| `npm run preview` | локальный просмотр собранного `dist/` |
| `npm run typecheck` | только проверка типов |
| `npm test` | все тесты один раз |
| `npm run test:watch` | тесты в режиме наблюдения |

## Управление

| Действие | Как |
|---|---|
| Двигать камеру | правая или средняя кнопка мыши, перетаскивание |
| Масштаб | колесо мыши (точка под курсором остаётся на месте) |
| Выделить ноду | клик; `Ctrl`/`Shift` + клик добавляет или снимает |
| Выделить рамкой | перетащить левой кнопкой по пустому месту |
| Переместить ноды | перетащить любую выделенную |
| Добавить ноду | правый клик (без перетаскивания) по пустому месту, открывается палитра с поиском |
| Соединить пины | потянуть от пина к пину; недопустимое соединение подсвечивается красным |
| Создать ноду из связи | отпустить протянутую связь над пустым местом, палитра покажет только совместимые ноды и сама подключит новую |
| Перенести связь | потянуть за занятый data-вход, связь «снимется» и потянется дальше от источника |
| Выбрать связь | клик по линии |
| Удалить | `Delete`: выбранную связь или выбранные ноды |
| Отменить / повторить | `Ctrl+Z` / `Ctrl+Y` (или `Ctrl+Shift+Z`), работает и в русской раскладке |

Тулбар: **New / Open / Save**, **↶ ↷**, **Run / Stop**, переключатель медленного режима и языка (ru/en).
Справа панель **Variables**: переменные графа и кнопки **Get / Set**, которые ставят ноду в центр экрана.

Граф **сохраняется автоматически** в `localStorage` и восстанавливается при открытии страницы. **Save** скачивает его файлом `graph-up.json`, **Open** загружает. Открытие файла и «New» можно отменить через `Ctrl+Z`.

## Как это устроено

Главная идея: **нода делится на определение и экземпляр**.

| | Что это | Где живёт |
|---|---|---|
| **Определение** (`NodeDef`) | тип ноды: пины, название, **код** | файл в `src/nodes/` |
| **Экземпляр** (`NodeInstance`) | нода на холсте: позиция, значения, ссылка на тип | в графе, это просто данные |

Поэтому граф превращается в обычный JSON, а код нод лежит в файлах и правится независимо от сохранённых графов.

### Пины и типы

- **exec** (белые стрелки) задаёт порядок исполнения. Из exec-выхода выходит одна связь, в exec-вход можно вести несколько (слияние потоков).
- **data** несёт значение. В data-вход ведёт одна связь, из выхода можно вести сколько угодно.

| Тип | Цвет | Примечание |
|---|---|---|
| `boolean` | красный | |
| `int` | бирюзовый | |
| `float` | салатовый | `int → float` разрешён, обратно нельзя (нужна явная конвертация) |
| `string` | розовый | |
| `any` | серый | подходит ко всему; только для пинов, переменной такой тип дать нельзя |

Циклы по **данным** запрещены (чистые ноды вычисляются рекурсивно), циклы по **exec** разрешены: это обычные циклы исполнения.

### Исполнение

- **Exec-ноды** выполняются по цепочке: нода вернула, какой exec-выход активировать (`next`), и исполнитель идёт по связи дальше.
- **Чистые ноды** (без exec-пинов, например `Add`) вычисляются лениво, когда кто-то запросил их выход. Результат кэшируется в пределах одного шага.
- **Вложенные цепочки.** Нода может вызвать `ctx.exec('имя_пина')`: выполнить цепочку от этого выхода и вернуться. Так устроен `For Loop`.
- **Переменные** стартуют со значения по умолчанию, `Get` работает и без предшествующего `Set`.
- Значения приводятся к типу пина: строка `"10"` из текстового поля попадёт в `float`-пин числом, а не склеится как строка.
- Исполняется **снимок** графа: правки во время запуска не влияют на текущий прогон.

**Защита от зависаний:** лимит шагов (по умолчанию 10 000), лимит глубины вложенности (100), кнопка **Stop** (`AbortSignal`) и периодическая отдача управления браузеру. Каждый запуск тела цикла считается шагом, поэтому даже пустое тело на миллиард итераций упрётся в лимит.

### Структура проекта

```
src/
  graph/        Ядро без Vue и DOM. Всё тестируется без браузера
    types.ts      типы: пины, NodeDef, Graph, Variable
    define.ts     defineNode(), data(), exec()
    registry.ts   реестр определений нод
    pins.ts       resolvePins/pinOf: пины конкретной ноды (могут зависеть от экземпляра)
    validate.ts   можно ли соединить пины (типы, циклы по данным)
    execute.ts    исполнитель графа
    variables.ts  переменные графа
    serialize.ts  формат файла и строгий разбор
  nodes/        Определения нод: файл на ноду, подхватываются автоматически
  editor/       Редактор: стор (Pinia), камера, холст, ноды, связи, палитра, история
  i18n/         Локализация (ru/en)
tests/          Vitest
```

### Как добавить ноду

Создай файл в `src/nodes/<категория>/<имя>.ts`. Реестр собирается через `import.meta.glob`, больше нигде регистрировать ничего не нужно. Нода сразу появится в палитре, в категории по префиксу id.

```ts
import { data, defineNode } from '@/graph/define';

export default defineNode({
    id: 'math/multiply',
    title: 'Multiply',
    inputs: { a: data('float', 1), b: data('float', 1) },  // 1 — значение по умолчанию
    outputs: { result: data('float') },
    run: ({ a, b }) => ({ outputs: { result: a * b } }),    // a и b уже number
});
```

- Нода **без exec-пинов** считается чистой и вычисляется по запросу. Чтобы сделать ноду, участвующую в потоке, добавь `in: exec()` и `out: exec()`. Единственный exec-выход активируется сам, а при нескольких верни `{ next: 'имя_выхода' }`.
- `run` получает `ctx`: `log()`, `exec(pin)` (вложенная цепочка), `setOutputs()` (опубликовать выходы до конца `run`, как индекс цикла), `vars` и `config`.
- Если пины зависят от экземпляра (как у `Get`/`Set` Variable), добавь `resolve(node, graph)`. Он накладывает свои пины поверх статических. **Читай пины через `resolvePins()`/`pinOf()`, а не из `def.inputs`.**
- `hidden: true` скрывает ноду из палитры.

### Локализация

Весь пользовательский текст идёт через `t('ключ')`. Ключи типизированы, поэтому опечатка станет ошибкой компиляции, а `en.ts` обязан повторять структуру `ru.ts`.

Названия нод и пинов устроены мягче: английский текст лежит в самом файле ноды, а переводы необязательны и живут в `nodeTexts` словаря. Новая нода работает без записи в словарях.

### Формат файла

```jsonc
{
  "format": "graph-up",
  "version": 1,
  "view": { "x": 0, "y": 0, "z": 1 },        // камера (необязательно)
  "graph": {
    "nodes": { "n1": { "id": "n1", "type": "flow/start", "x": 40, "y": 120, "values": {} } },
    "connections": [{ "id": "c1", "from": { "node": "n1", "pin": "out" }, "to": { "node": "n2", "pin": "in" } }],
    "variables": [{ "id": "v1", "name": "sum", "type": "float", "default": 0 }]
  }
}
```

Файл читается строго: не-JSON, чужой JSON, повреждённая структура, неизвестный тип ноды и опасные id (`__proto__`) отклоняют загрузку целиком. Недопустимые связи (несуществующие пины, несовместимые типы, лишние связи в один вход) отбрасываются, а их число показывается пользователю. Файл более новой версии не открывается.

## Ограничения (на сегодня)

- Переменные могут быть только `boolean`, `int`, `float`, `string`. Пользовательских типов и классов нет.
- Нет массивов, структур и собственных функций/макросов.
- Нод немного: `Start`, `Branch`, `For Loop`, `Add`, `Greater`, `Print`, `Get`/`Set` Variable.
- Причину запрета соединения пользователь не видит, пин просто краснеет.
- История undo хранит снимки графа целиком (до 100 шагов). Для сотен нод это нормально, для тысяч стоит перейти на дельты.
- Зависимость `@1337exp/taoui` подключена, но пока не используется: UI панелей написан на обычном Vue.
